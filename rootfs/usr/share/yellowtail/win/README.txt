Yellowtail: after installing Windows

1. Keyboard layout, the same French (QWERTY) as on Linux: install
   Microsoft Keyboard Layout Creator 1.4 from microsoft.com, open
   fr-qwerty.klc, choose Project > Build DLL and Setup Package, run
   setup.exe from the folder it built, then in Settings > Time & language
   > Language & region, add the keyboard "French (QWERTY)" to your
   language and remove the US one.

2. Caps Lock swapped with Ctrl: double-click swap-caps-ctrl.reg, accept,
   and reboot.

3. Japanese input: install Google Japanese Input, the Windows sibling of
   Mozc, or add Microsoft IME under the Japanese language in the same
   Settings page.
